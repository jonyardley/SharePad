# Drawing script for the hour runs

The same work on both paths, so the battery and CPU numbers compare. Repeat the
loop for an hour, with the Mac showing the share window the whole time.

1. Pen tool: write a line of handwriting across the page, slowly (1 minute).
2. Pen tool: scribble fast in one corner for 30 seconds.
3. Lasso a block of strokes and drag it across the page (30 seconds).
4. Open the paper menu, switch to grid, then back to plain (15 seconds).
5. Rest with the pencil down for 1 minute, nothing moving.
6. Clear, then start the loop again.
